## Исправления, выявленные live-проверкой

1. Twenty возвращает пустые nullable TEXT как `""`: нормализованы receipt/lock покупки пакета. Повтор первоначального запроса восстановил тот же пакет, одну оплату и одно начисление.
2. Отмена разового участника направлялась в пакетную команду: подключён штатный cancel-pay-as-you-go и корректный маршрут повтора.
3. Создание смешанной прошедшей группы превышало короткие таймауты: CRM 60 с, API 65 с, UI 70 с, nginx 75 с. Остальные UI-запросы сохраняют прежний короткий таймаут.
4. Отмена разовой записи не обновляла сохранённый bookedCount: добавлен существующий пересчёт вместимости; подтверждено live.
5. CLI загружает файлы параллельно и превышает лимит 30 запросов/30 секунд. После проверки оставшегося плана применена локальная задержка 1,25 с между Axios-запросами, без изменения серверного лимита/SDK. Один дополнительный обрыв загрузки файла случился до sync manifest; повторная ограниченная загрузка завершилась успешно.
