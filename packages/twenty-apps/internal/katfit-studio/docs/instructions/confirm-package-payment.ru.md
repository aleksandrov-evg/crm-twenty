# Как оформить оплату пакета клиента

Эта инструкция нужна оператору, когда клиент полностью оплатил пакет занятий. После подтверждения система создаёт оплату, пакет клиента и начисляет посещения.

## Перед началом

Убедитесь, что:

- клиент уже есть в CRM;
- нужный групповой или персональный пакет создан в разделе **Продукты студии** и включён переключателем **Доступен для продажи**;
- у продукта указаны цена и количество посещений;
- получена полная оплата за один пакет.

Если продукта нет в списке формы, не оформляйте оплату вручную через поля баланса. Сначала попросите администратора создать или включить нужный продукт.

## Оформить оплату

1. В левом меню откройте раздел **Люди**.
2. В строке поиска найдите клиента по имени, телефону или email.
3. Нажмите на имя клиента, чтобы открыть его карточку.
4. В правом верхнем углу карточки откройте меню действий **⋯**.
5. Нажмите **Оформить оплату пакета**.
6. В открывшейся форме в поле **Пакет** выберите оплаченный клиентом пакет.
7. Проверьте поле **Дата и время оплаты**. При необходимости укажите фактические дату и время получения денег.
8. В поле **Способ оплаты** выберите одно значение:
   - **Наличные**;
   - **СБП**;
   - **Карта**.
9. Если известны номер транзакции, платёжной ссылки или ID из внешней системы, заполните поле **Внешний ID**. Если есть номер фискального чека, заполните **ID чека**.
10. Проверьте блок внизу формы:
    - сумму к оплате;
    - сколько посещений будет начислено;
    - срок пакета, если он задан для продукта.
11. Нажмите **Подтвердить оплату**.
12. Дождитесь сообщения **«Пакет оформлен»**. Оно содержит число начисленных посещений.

## Проверить результат

1. Откройте в карточке клиента связь **Пакеты студии**.
2. Нажмите на новый пакет.
3. Проверьте:
   - **Статус** — `Активен`;
   - **Начислено** — число занятий из выбранного пакета;
   - **Доступно** — то же число, если по пакету ещё не было списаний;
   - **Цена покупки** — цена выбранного продукта.
4. В связи **Оплаты** откройте созданную оплату и убедитесь, что её статус — `Оплачено`.
5. В связи **Операции** пакета проверьте, что есть строка **Начисление** на число купленных посещений.

## Если что-то пошло не так

| Ситуация                                     | Что сделать                                                                                                                           |
| -------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| Нужного пакета нет в списке                  | Не меняйте баланс вручную. Попросите администратора создать продукт или включить **Доступен для продажи**.                            |
| Сумма на форме не соответствует оплате       | Не подтверждайте операцию. Для скидки, доплаты или частичной оплаты требуется отдельное решение администратора.                       |
| Клиент оплатил два пакета                    | Оформите каждый пакет отдельной операцией. Не объединяйте две оплаты в один пакет.                                                    |
| Кнопка **Подтвердить оплату** вернула ошибку | Не нажимайте кнопку с новыми данными. Зафиксируйте время и обратитесь к администратору; повтор с теми же данными безопасен.           |
| Ошибочно оформили оплату                     | Не исправляйте поля **Начислено**, **Доступно** или строку операции вручную. Обратитесь к администратору для компенсирующей операции. |

## Чего не делать

- Не создавайте оплату, пакет и остаток тренировок по отдельности вручную.
- Не меняйте вручную поля **Начислено**, **Использовано** и **Доступно**.
- Не используйте одну оплату для нескольких пакетов и не собирайте один пакет из нескольких оплат.
- Не подтверждайте сумму, отличающуюся от цены выбранного пакета.
