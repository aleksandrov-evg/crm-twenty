# Работа со сплитами

Сплит — это тренировка для двух закреплённых клиентов в одном слоте. В CRM у пары один общий блок и один общий остаток: проведённая тренировка уменьшает остаток на **1**, а не на 2.

## Перед началом

Проверьте, что:

- оба человека уже созданы как клиенты в CRM;
- у продукта сплита стоит категория `SPLIT`, формат `SPLIT_EQUIPMENT`, 4 тренировки и цена 20 000 ₽;
- в продукте задана **Вместимость слота по умолчанию**: для выделенного сплит-слота — `2`;
- для записи заранее создано занятие с форматом `SPLIT_EQUIPMENT`, будущим временем и вместимостью не меньше 2.

Не создавайте для сплита два независимых пакета или два отдельных остатка у клиентов.

## 1. Создать пару

1. Откройте раздел **Пары**.
2. Создайте запись пары.
3. Укажите понятное название, например «Анна Иванова + Мария Петрова».
4. В полях **Первый участник** и **Второй участник** выберите двух разных клиентов.
5. Оставьте статус **Активна**.

Если один из участников меняется, не редактируйте историю проведённых занятий. Сначала согласуйте замену со студией, затем создайте новую пару для новых продаж и записей.

## 2. Продать общий сплит-блок

1. Откройте карточку пары.
2. В меню команд выберите **Оформить сплит-блок**.
3. Выберите сплит-продукт и укажите дату оплаты.
4. Выберите способ оплаты.
5. Оставьте переключатель **Два платежа по половине**, если каждый участник платит по 10 000 ₽. Снимите его, если один участник оплачивает всю сумму 20 000 ₽.
6. Подтвердите оплату.

После успешной операции CRM создаст один общий блок с остатком 4 совместных тренировки и одну или две записи оплаты. Блок активируется только при полной сумме. Чек или чеки необходимо оформить по рабочему процессу кассы и внести их ID при использовании API; форма продажи пока не содержит отдельного поля для ID чека.

## 3. Внести программу и создать сплит-слот

«Программа» для сплита в CRM — это конкретный слот занятия, а не персональный план упражнений.

1. Откройте раздел **Занятия**.
2. Создайте занятие.
3. В поле **Продукт-источник** выберите сплит-продукт. CRM подставит название, формат, длительность и вместимость из продукта.
4. Проверьте начало и окончание, вместимость не менее 2, статус **Запланировано** или **Подтверждено**. При необходимости измените эти значения только для конкретного слота.
5. В блоке **«Доступные сплиты»** выберите пару по именам обоих клиентов, например **«Анна Иванова — Мария Петрова»**, и убедитесь, что рядом есть положительный остаток.
6. Нажмите **Создать занятие**.

Постоянное время для сплита не обещается: для каждого согласованного занятия создавайте отдельный слот либо используйте уже созданный свободный слот.

При выборе сплит-формата блок **«Доступные сплиты»** появляется сразу. В нём каждая доступная пара показана понятным названием участников: **«Клиент 1 — Клиент 2»**. В список попадают только пары с активным общим блоком и остатком больше нуля.

## 4. Записать пару на слот

Основной способ — выбрать пару ещё при создании занятия: отдельное сохранение для записи не требуется.

1. При необходимости откройте уже созданный сплит-слот в **Расписании**.
2. В блоке **«Доступные сплиты»** выберите нужную пару по именам обоих клиентов, например **«Анна Иванова — Мария Петрова»**.
3. Убедитесь, что рядом показан положительный общий остаток.
4. Нажмите **Сохранить**.
5. Убедитесь в сообщении «Занятие сохранено, сплит назначен» и при необходимости откройте раздел **Записи**.

CRM создаст две записи — по одной на каждого клиента — и зарезервирует одну тренировку из общего блока. Для записи нужно два свободных места. Не создавайте две обычные записи вручную: тогда общий резерв не будет учтён.

### Короткая схема

```text
Продукт → Расписание: создать слот → «Доступные сплиты»
                                     → выбрать пару → «Создать занятие»
                                     → CRM создаёт слот, 2 записи и 1 резерв
```

## 5. Отметить проведённое занятие

После окончания слота:

1. Откройте любую из двух записей пары в разделе **Записи**.
2. Выберите команду **Управление сплит-записью**.
3. Нажмите **Отметить пару проведённой**.

Обе записи получат статус «Посетил». Резерв закроется, а общий остаток блока уменьшится на одну тренировку. В статистике это два клиентских визита, но одна проведённая сплит-тренировка.

## 6. Отмена и перенос

### Пара отменяет слот вовремя

1. Откройте любую запись пары.
2. Выберите **Управление сплит-записью** → **Отменить слот пары**.

Своевременной считается отмена не позднее чем за 12 часов до начала. Резерв освобождается, остаток не уменьшается. Для пары разрешён только один такой перенос за 30 дней.

### Один участник отменяет поздно или не приходит

1. Откройте запись отсутствующего клиента.
2. Выберите **Управление сплит-записью** → **Поздняя отмена этого участника**.

Отсутствующий получит статус «Поздняя отмена». Второй участник сохраняет свою запись и может заниматься один в исходное время. CRM спишет одну совместную тренировку; занятие не становится персональным и не создаёт отдельный остаток для отсутствующего клиента.

### Студия отменяет слот

Пока для отмены студией нет отдельной команды. Не списывайте тренировку вручную. Зафиксируйте причину в записи занятия, отмените слот и согласуйте новое время либо продление блока с владельцем до появления отдельного процесса.

## Контроль перед закрытием смены

- У каждой проданной пары один общий блок, а не два пакета.
- У каждого сплит-слота две связанные записи.
- Для проведённого слота списана одна тренировка общего блока.
- При поздней отмене одного клиента запись второго не отменена.
- Остаток блока и журнал операций не корректируются вручную.
